# 🎵 Discord Music Bot

A modern, minimal, and high-quality Discord music bot built with Python. Designed to deliver seamlessly high-quality audio playback for your server.

## ✨ Features

- 🎧 **High-Quality Audio:** Smooth streaming without lags or interruptions.
- 🎨 **Modern & Minimal:** Clean output messages and easy-to-use commands.
- 🔗 **Multi-Platform Support:** Works with YouTube and Spotify links.
- ⚡ **Slash Commands:** Fully supports modern Discord `/` commands.

## 🛠️ Commands

| Command | Description |
| :--- | :--- |
| `/play <song/link>` | Play a song using a name, Spotify link, or YouTube URL. |
| `/stop` | Stop playback and disconnect the bot from the voice channel. |
| `/pause` | Pause current track. |
| `/resume` | Resume playing paused track. |
| `/skip` | Skip to the next song in the queue. |
